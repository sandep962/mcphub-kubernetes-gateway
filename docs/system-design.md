# MCPHub System Design

## Goal
Build a team MCP gateway on Kubernetes for a WooCommerce store.

## Core components
- React dashboard
- Gateway backend and MCP endpoint
- WooCommerce MCP server
- Two additional upstream MCP servers
- WooCommerce, WordPress, and database
- AI chat agent
- Kubernetes and Helm deployment

## Security
- Admin and member roles
- Hashed, revocable API keys
- Server-side upstream credentials
- Tool-call audit logging

## Status
Initial project structure created. Detailed design will be updated
as components are implemented and tested.
